# ScamShield ID
AI Agent (IBM Bob) untuk menganalisis pesan penipuan digital berbahasa Indonesia.

## Fungsi
Tempel pesan mencurigakan → dapat verdict, skor risiko, red flag, dan langkah aman.

## Struktur Prompt
Layer 1: Role & Context | Layer 2: Task & Requirement | Layer 3: Constraints & Output
Lihat `prompt/prompt-final.md`.

## Cara Menjalankan
1. Buka agent di IBM Bob
2. Tempel pesan yang ingin dicek
3. Baca hasil analisis

## Pengujian
10 pesan uji (penipuan dan pesan sah), hasil di `testing/hasil-uji.md`.

## Pengembangan Lanjutan
Analisis screenshot, cek link/nomor, bot WhatsApp, mode edukasi.
